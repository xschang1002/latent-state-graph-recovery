# Submission and release materials

These files accompany *State Aggregation in Dynamic Graph Recovery: Separating
Structural Ranking from Temporal Discrimination*. The
[research guide](../../docs/research_guide.md) describes the scientific scope;
the [reproduction guide](../../docs/information_sciences_artifact_readme.md)
gives the executable routes.

| File | Purpose |
|---|---|
| `cover_letter.docx`, `cover_letter.txt` | Introduce the evaluation question and controlled evidence to Information Sciences. |
| `highlights.docx`, `highlights.txt` | Five items, each at most 85 characters including spaces. |
| `title_page.docx` | Author, correspondence and confirmed full institutional address. |
| `author_biography.docx`, `author_biography.txt` | Factual biography of fewer than 100 words. |
| `declaration_of_competing_interest.docx` | Authored no-conflict statement; this is not a form generated by the publisher's Declaration Tool. |
| `declarations.txt` | Author-supplied funding, interests, CRediT, availability and AI-use statements. |
| `manuscript_source.zip`, `supplement_source.zip` | Separate flat LaTeX source packages for the submission system. |
| `CITATION.cff`, `deposit_metadata.json`, `upload_description.md` | Citation and release metadata. |

[latent-state-graph-recovery](https://github.com/xschang1002/latent-state-graph-recovery).

## Final journal-system checks

Publication of a GitHub release does not submit the article to the journal.

1. Review and approve the final article, supplement, cover letter, highlights,
   biography and declarations. Complete the publisher's actual Declaration Tool
   and upload its generated form where requested. The supplied authored
   no-conflict DOCX does not certify completion of that tool.
2. Supply a real author photograph if requested by the journal. No photograph
   is included; none has been generated or inferred.
3. The directly inspected journal guide on 24 October 2026 advised 40
   double-spaced pages and eight combined figures/tables for experimental
   articles. The current article has 26 double-spaced pages, six figures and
   five tables. Confirm acceptance of the 11 displays with the editor or
   submission system; the advisory count has not been treated as a verified
   automatic rejection rule or used to remove scientific evidence.
4. Upload the current manuscript, supplement, editable highlights, requested
   author materials and source files. Check the actual system's attachment
   size limits: acceptance of the approximately 310 MB reproducibility ZIP
   has not been verified. The complete ZIP is accessible through the public
   release; if the system cannot accept it, supply that download link and
   follow the journal's instructions for externally hosted research material.
5. Open the system-generated merged PDF after upload and check formulas,
   figures, tables, cross-references and attachment completeness. That PDF
   can only be checked after an actual submission-system upload.
6. Record the final author approval, submission identifier and upload receipt
   separately. No journal submission or acceptance is claimed by this archive.

## Requirement sources and verification dates

- [AI policy](https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals): accurate disclosure and author responsibility.
