# State aggregation in dynamic graph recovery

This Knowledge-Based Systems reproducibility and transfer package accompanies
the article "State Aggregation in Dynamic Graph Recovery: Separating Structural
Ranking from Temporal Discrimination" by Xuansong Chang.

The package supplies the current manuscript and supplement, flat source ZIPs,
retained simulation inputs and fitted outputs, protocols, analysis and plotting
code, and verification/rebuilding instructions. All scientific data, fitted
outputs, numbers, displays, code and inference are unchanged from public release
v2026.10.28-layout.1; the KBS presentation adds relational-knowledge framing,
first-use acronym expansions and formal Propositions 1--3 and S1--S4.
The public GitHub release version is `v2026.11.15-kbs`; no DOI has been assigned.

running verification. Saved-output verification, display rebuilding and new
simulation/fitting are separate routes. No new simulations or fitting were
performed for the venue change. Third-party sources retain their notices and
acquisition conditions.
