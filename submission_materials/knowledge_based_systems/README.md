# Knowledge-Based Systems transfer materials

Preparation date: 15 November 2026. Public release version:
`v2026.11.15-kbs`. The author confirmed that Information Sciences rejected the
manuscript and that the next submission uses Elsevier's transfer service.
This package does not record a completed transfer or a new editorial decision.

The scientific contribution is an evaluation protocol and formal diagnostic
evidence (Propositions 1--3 and S1--S4) for separating structural ranking,
within-edge temporal discrimination and boundary detection in dynamic
relational graph recovery. All scientific data, fitted outputs, numbers,
displays, code and inference remain unchanged from public release
v2026.10.28-layout.1; no new algorithm claim or experiment is introduced by the
venue change.

## Complete the existing Elsevier transfer workflow

1. Replace transferred upload files with this KBS manuscript, supplement,
   transfer letter and Highlights where the system permits. Retain any required
   transfer history and earlier correspondence; do not label it a first submission.
2. Confirm the KBS article type, anonymity instructions, source-file requirements,
   reference style and attachment limits in the actual transfer system. The
   current identified manuscript and author-year references are retained because
   the live KBS guide was inaccessible; this is not a claim of verified KBS format.
3. Use the author's confirmed funding/interest/AI statements. If a publisher
   declaration tool is requested, complete it through the system; the authored
   DOCX is not evidence that this has been done.
4. Use the public release URL above (`https://github.com/xschang1002/latent-state-graph-recovery/releases/tag/v2026.11.15-kbs`) if externally hosted
   reproducibility material is linked in the submission system.
5. Check the system-generated combined PDF, including equations, figures,
   tables, citations, author information and supplementary attachments. Final
   submission remains the author's action.
